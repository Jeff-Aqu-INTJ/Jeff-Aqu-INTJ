## What I'm working on

### Synchronised Multichannel Neuro-Signal Monitoring System

My final-year project explores modular hardware for physiological signal acquisition. My undergraduate scope is a **seven-slot motherboard and an ECG + respiration acquisition card**, as part of a broader portable monitoring system.

I'm particularly interested in how signals from separate acquisition modules can be brought together into a coordinated system.
